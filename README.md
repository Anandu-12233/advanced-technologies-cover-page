# Advanced Technologies Cover Page

A responsive, visually styled cover page for "Advanced Technologies" — built with HTML, CSS, and Bootstrap 4.

##  Overview

This project is a clean, card-based landing/cover page that presents the concept of advanced technologies with a title, brief description, and two call-to-action buttons — **Learn More** and **Save Draft**.

## Project Structure

```
advanced-technologies-cover-page/
├── index.html       # Main HTML structure
└── styles.css       # Custom styles and layout
```

## 🛠️ Tech Stack

- **HTML5** — Semantic markup
- **CSS3** — Custom styles (`styles.css`)
- **Bootstrap 4.5.2** — Grid, flexbox utilities, and responsive layout
- **jQuery 3.5.1** — Bootstrap JS dependency
- **Popper.js 1.16.1** — Bootstrap JS dependency

## Getting Started

No build tools or installation required. Just open the project in your browser:

```bash
# Clone the repository
git clone https://github.com/Anandu-12233/advanced-technologies-cover-page.git

# Open in browser
cd advanced-technologies-cover-page
open index.html
```

Or simply double-click `index.html` to view it locally.

##  Features

- Full-screen background container using Bootstrap's flexbox utilities
- Centered content card with title, description, and action buttons
- Custom CSS classes for the card, title, description, and buttons
- Clean separation of structure (`index.html`) and presentation (`styles.css`)
